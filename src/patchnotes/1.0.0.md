# 🎉 1.0.0 - fresh outta beta!

hey all! i'm glad to announce avali is now out of beta!
this update brings some nice features i hope yall will enjoy!

## - 📜 download queue!

there's now a download queue! you can queue up videos and have them downloaded one after another!

this queue also shows things like download progress, filesize, lets you redownload videos you've downloaded this session, and remove items from queue.

## - 📹 format selection!

you can now pick which format your video downloads at! pretty self-explanitory

## - 📱 mobile improvements!

website works a lot beter on mobile now!

## - 🚢 selfhosting!

you can selfhost avali now in docker!
